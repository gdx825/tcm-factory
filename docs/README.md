## 关于文档与代码的关系

四份文档描述的**都是已实现的功能**，不是待办计划。文中标注「⚠️ 踩坑记录」的段落，
记录的是实现期由单元测试抓出的真实缺陷——它们有一个共同特征：
**编译通过、界面正常，只有用起来才会发现不对**。

例如：

- 遗忘曲线首档 5min 被永久跳过（`level` 与阶梯错位一档）
- 清洗器不认识古籍的「光杆标题」，导致章节结构崩坏
- 题库 `type` 默认值不当，使题型自动推断形同虚设
- 答案在库里存两种格式，读取端只认一种 → 答错时不显示正确答案

这些如果不记录，下一个人（很可能就是几个月后的自己）会重新踩一遍。
